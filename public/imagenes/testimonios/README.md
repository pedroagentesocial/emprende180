# `/public/imagenes/testimonios` — las caras de los testimonios

Un archivo por persona, con el mismo nombre que su entrada en
`testimonios` (`src/config/curso.config.ts`): **400×400 px**, cuadrado,
recortado a la cara, menos de 60 KB.

06-10-2026 para que el testimonio no salga con las iniciales mientras llegan
las fotos reales. **No son las personas que firman el testimonio.** El `alt`
del avatar va vacío a propósito (es decoración y no afirma quién es), pero
conviene cambiarlas por la foto de cada persona en cuanto estén.
